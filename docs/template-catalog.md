# デザインテンプレートカタログ

## 分類の責務

各テンプレートは、目的を表すベンダーニュートラルな `primaryCategory` を必ず1つ持つ。主カテゴリはカタログの主要な探索経路であり、同じテンプレートを複数カテゴリへ重複掲載しない。AWS、Azure、GCPなどのサービス名は主カテゴリに含めない。

`tags` は、関連概念、技術特性、横断的な関心事を複数付与する補助メタデータである。タグは主カテゴリを置き換えず、将来の絞り込みに使う。Provider情報を追加するときもタグ相当の独立したメタデータとして拡張し、カテゴリ階層へ結合しない。

カタログモデルは `src/lib/catalog` に置き、Scenarioや描画エンジンの状態・ノード・接続モデルを参照しない。テンプレートカードの `href` だけが個別テンプレートへの導線を担う。

## 表示ルール

- 利用可能なテンプレートを持つカテゴリを先に表示する。
- 0件のカテゴリも一覧から除外せず「Planned」と表示する。
- 0件のカテゴリ詳細では、将来追加予定であることとカテゴリ一覧へ戻る導線を表示する。
- カテゴリカードとテンプレート詳細導線はネイティブリンクとし、キーボードで到達・実行できるようにする。
- 選択状態や提供状況は色だけに依存せず、テキストラベルでも示す。
